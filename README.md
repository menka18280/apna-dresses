Apna Dresses — Static site

This is a simple multi-page static site for the Apna Dresses shop.

How to publish to GitHub Pages (project site):
1. Create a new GitHub repository (e.g., apna-dresses).
2. Add the repository as remote and push the gh-pages branch:
   git remote add origin https://github.com/USERNAME/apna-dresses.git
   git push -u origin gh-pages
3. In the repository Settings → Pages, select the gh-pages branch as the source and save.

Alternatively, create a repo named USERNAME.github.io and push to main to host as a user site.
